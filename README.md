# Teste DISC

Avaliação comportamental DISC gratuita, em português, baseada no modelo de William Moulton Marston (1928).

- 28 blocos de escolha forçada (“Mais” / “Menos”), com itens originais
- Relatório com os quatro fatores, padrão combinado (12 estilos), análise por fator e orientações práticas
- Gráficos: perfil geral, mapa de estilo (ritmo × foco), Mais × Menos e distribuição
- Resultado compartilhável por link, exportação em PDF, modo claro/escuro
- 100% estático: as respostas ficam apenas no navegador

## Rodar localmente

```sh
python -m http.server 8000
```

Depois abra http://localhost:8000.

## Limitações

Ferramenta de autoconhecimento, não um instrumento psicométrico validado. Escores de escolha forçada são ipsativos e não devem ser usados para comparar pessoas ou em decisões de contratação. As fontes estão na própria página.
